# 사운드 딜레이 (Sound Delay)

스마트폰에서 재생 중인 오디오(유튜브 등)를 **0.5초 ~ 20초** 사이에서 설정한 시간만큼
지연시켜 블루투스 이어폰으로 들려주는 안드로이드 앱입니다.

화면은 TV(미러링 등으로 지연됨), 소리는 스마트폰에서 나올 때 둘의 싱크가 어긋나는
문제를 해결하기 위해 만들어졌습니다. 폰 쪽 소리를 TV 화면 지연만큼 늦춰서 맞춥니다.

## 동작 원리

- Android 10+의 **AudioPlaybackCapture API**(MediaProjection)로 다른 앱의 재생 오디오를
  실시간 캡처합니다. 화면은 녹화하지 않고 소리만 사용합니다.
- 캡처한 오디오를 링 버퍼(48kHz/16bit/스테레오)에 쌓았다가 설정한 시간만큼 늦게
  `AudioTrack`으로 재생합니다. 재생 중에도 0.1초 단위로 지연 시간을 조절할 수 있습니다.
- 안드로이드는 원본 앱의 소리를 강제로 끌 수 없으므로, **원본은 미디어 볼륨을 0으로
  낮춰서 소거**합니다. 내부 오디오 캡처는 기기 볼륨과 무관하게 원본 레벨로 잡히기
  때문에 미디어 볼륨이 0이어도 캡처는 정상 동작합니다.
- 지연된 소리는 기본적으로 **알람 볼륨 채널**(`USAGE_ALARM`)로 출력해 미디어 볼륨과
  독립적으로 크기를 조절합니다. 기기에 따라 알람 채널이 스피커로도 울리는 경우가
  있어, 앱에서 미디어/접근성 채널로 바꿀 수 있습니다.
- 출력 트랙에는 `ALLOW_CAPTURE_BY_NONE`을 설정해 자기 출력이 다시 캡처되는
  무한 에코를 방지합니다.
- 포그라운드 서비스로 동작하므로 화면을 꺼도 계속 재생됩니다.

## 사용 방법

1. 블루투스 이어폰을 연결합니다.
2. 앱에서 지연 시간을 설정하고 **시작**을 누릅니다.
3. 화면 캡처 허용 창에서 허용을 누릅니다.
4. **미디어 볼륨을 0으로** 낮춰 원본 소리를 끕니다. 지연된 소리의 크기는
   **알람 볼륨**으로 조절합니다.
5. 영상을 보면서 ±0.1초 버튼으로 싱크를 미세 조정합니다.

> 넷플릭스·스포티파이처럼 오디오 캡처를 차단하는 앱은 지원되지 않습니다.
> 유튜브는 지원됩니다. 블루투스 자체 지연(약 0.1~0.3초)은 미세 조정으로 흡수하면 됩니다.

## 빌드

- **요구 사항**: Android Studio (또는 Android SDK 34 + JDK 17), minSdk 29 (Android 10)
- Android Studio에서 이 폴더를 열고 Run 하거나, 명령줄에서:

```bash
./gradlew assembleDebug
# APK 위치: app/build/outputs/apk/debug/app-debug.apk
```
